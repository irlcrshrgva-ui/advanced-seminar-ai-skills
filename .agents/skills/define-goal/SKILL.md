# Define Goal

Use this skill when a task needs clearer success criteria before work starts.

## Workflow
1. Restate the intended outcome in concrete terms.
2. Identify the artifact, repository, feature, or behavior being changed.
3. Define how completion will be verified.
4. Add measurable or binary success criteria where practical.
5. Clarify important scope limits and stop conditions.
6. Avoid vague goals such as "make it better" when a verifiable result can be stated instead.

## Output
Return a short objective that explains what should be true when the task is complete and what evidence will prove it.
