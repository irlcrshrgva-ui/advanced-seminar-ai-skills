# Writing Guidelines

Review files for compliance with Vercel's Writing Guidelines.

## How It Works
1. Fetch the latest guidelines from Vercel's writing-guidelines source.
2. Read the specified files.
3. Check the content against the current rules.
4. Report findings concisely with file and line references when possible.
