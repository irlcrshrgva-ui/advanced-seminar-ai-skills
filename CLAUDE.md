# CLAUDE.md

## Project Overview
This is an Advanced Seminar repository demonstrating Git branching, AI project context, agent instructions, and reusable skills.

## Before Working
1. Read `knowledge.md` for project context.
2. Read `AGENTS.md` for repository-wide rules.
3. Confirm that work is happening on `feature/ai-skills-setup` rather than `main`.

## Preferred Working Style
- Keep solutions simple and academically explainable.
- Use clear Markdown and meaningful file names.
- Avoid adding frameworks, dependencies, or code unless the task requires them.
- When creating or updating a skill, make the workflow explicit enough that another AI assistant can follow it consistently.

## Review Expectations
When reviewing repository changes, check for:
- correctness,
- readability,
- unnecessary complexity,
- missing documentation,
- unsafe Git operations,
- accidentally committed secrets.

## Completion Format
At the end of a task, provide a concise summary of changed files, important decisions, and any steps that still require manual verification.
