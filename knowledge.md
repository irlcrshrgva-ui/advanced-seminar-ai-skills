# Project Knowledge

## Course Context
This repository was created for an Advanced Seminar activity about modern AI-assisted development workflows.

## Main Objectives
- Practice safe Git branching before modifying a project.
- Provide persistent project context for AI assistants.
- Define clear instructions for agentic coding tools.
- Build reusable custom skills that can support future project work.
- Document how external AI-provider skills can complement the project.

## Project Scope
The repository is intentionally lightweight and documentation-first. It demonstrates how AI agents can be guided by structured Markdown files and reusable skill definitions without requiring a large application codebase.

## Important Conventions
- `main` is the stable branch.
- Assignment work is performed on `feature/ai-skills-setup`.
- AI-generated changes should be easy to review, explain, and reverse.
- Do not merge assignment work into `main` until it has been checked.
- Documentation should remain concise, readable, and suitable for academic submission.

## Current Custom Skills
1. Documentation Assistant — improves project documentation while preserving meaning.
2. Code Review Assistant — reviews code or configuration changes for clarity, correctness, and maintainability.

## Expected Evidence for Submission
Useful evidence may include screenshots of the branch list, repository file tree, custom skill files, and commit history showing that work was completed on a separate branch.
