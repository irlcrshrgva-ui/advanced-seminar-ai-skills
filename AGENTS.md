# AGENTS.md

## Purpose
This file gives AI coding agents clear operating instructions for this repository.

## Repository Rules
- Read `knowledge.md` before making changes.
- Treat `main` as stable and do not modify it directly for assignment work.
- Work on `feature/ai-skills-setup` or another explicitly approved feature branch.
- Keep changes small, reviewable, and clearly documented.
- Prefer simple Markdown-based solutions unless code is genuinely necessary.
- Do not invent project requirements that are not stated in the repository.
- Preserve existing files unless a change is required by the task.

## Quality Checklist
Before finishing a task:
1. Confirm the requested files exist in the correct paths.
2. Check Markdown formatting and heading hierarchy.
3. Verify custom skills have a clear purpose, inputs, procedure, and output expectations.
4. Ensure no secrets, credentials, or personal tokens are committed.
5. Summarize what changed and what still needs human review.

## Git Guidance
- Use descriptive commit messages.
- Avoid force-pushing or destructive history edits.
- Do not merge into `main` without explicit approval.
- Keep assignment evidence easy to identify in commit history.

## AI Behavior
Agents should explain assumptions, avoid unnecessary complexity, and prefer maintainable output over clever output.
