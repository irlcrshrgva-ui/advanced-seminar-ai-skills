# Define Goal

## Overview
Shape an intention into an objective with a verifiable outcome, clear scope, and evidence of completion.

## Workflow
1. Confirm that the user wants to define or refine a goal.
2. State the outcome, relevant artifact, and completion evidence.
3. Add measurable success criteria when appropriate.
4. Ask for clarification only when the missing information changes the outcome.
5. Do not claim to have created a goal in an external goal service without using that service.

## Quality Bar
A good goal explains what will be true when done, how it will be checked, and what is out of scope.
