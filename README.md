# Advanced Seminar – AI Skills Repository

This repository is for an Advanced Seminar activity focused on Git branching, AI agent configuration, project knowledge files, and reusable custom skills.

## Activity Requirements

1. Create and work on a separate Git branch before making assignment changes.
2. Add project AI context files: `knowledge.md`, `AGENTS.md`, and `CLAUDE.md`.
3. Create at least two project-specific custom skills.
4. Include or document compatible skills from AI providers such as OpenAI, Claude, Vercel, or others when appropriate.

## Repository Structure

- `README.md` – project overview
- `knowledge.md` – project knowledge base
- `AGENTS.md` – instructions for AI coding/agent tools
- `CLAUDE.md` – Claude-specific project guidance
- `skills/documentation-assistant/SKILL.md` – custom documentation skill
- `skills/code-review-assistant/SKILL.md` – custom code review skill
- `provider-skills.md` – notes on external provider skills and how they fit the project

All assignment changes are developed on the `feature/ai-skills-setup` branch before being considered for merge into `main`.
